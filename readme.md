# Exercício final código criativo 

Para o projeto final decidi utilizar como Input uma fotografia e transformá-la em ascii art obtendo assim como resultado em que quanto mais escuras forem as zonas de sombra da imagem, mais densidade de caracteres terá essa mesma zona e quanto mais brilho tiver as zonas de luz, menor será a densidade de caracteres. Recriando assim a imagem utilizada como input. 
Para este projeto comecei por colocar a imagem pretendida na pasta do ficheiro onde já estavam os conteúdos do index.html, readme, sketch.js e o style.css. 
Primeiro criei a variável "let img", de seguida a função "function preload"->"img=loadimage("tobias.jpg") para poder carregar a imagem para o projeto.
De seguida no "function setup"-> "createCanvas" coloquei o tamanho que corresponde à imagem original e coloquei um background(220).
Adicionei a variável "let size" e na function setup recalculei o tamanho da imagem. 
Para poder mapear o brilho de cada pixel da imagem adicionei a variável "let asciiChar" que consequentemente gerou a linha de caracteres ""@", "#", "S", "%", "?", "*", "+", ";", ":", ",", ".", utilizei um loop "for (let i=0, i<img.width, i++)" e "for (let j = 0; j<img.height; j++) para o mapeamento dos pixeis. Para obter os valores de cor dos pixeis específicos utilizei a variável "let pixelVal = img.get(i, j)" e "let c = brightness(pixelval)". para calcular o brightness value utilizei a função de mapeamento "let tIndex = floormap(c, 0, 100, 0, asciiChar.length)". Por fim incluí os elementos de texto para a composição com "let x = i*size + size/2", "let y = j*size + size/2"para definir o tamanho dos caracteres, "let t = asciiChar.charAt(tIndex)" para restituir os caracteres na linha de código "let asciiChar" e "textalign(CENTER, CENTER)", "text(t, x, y)" para centralizar e alinhar os caracteres.
